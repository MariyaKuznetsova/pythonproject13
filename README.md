# Проект платформы для онлайн-обучения

## Описание:

Проект платформы для онлайн-обучения

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:MariyaKuznetsova/pythonproject13.git 
```
2. Создайте файл .env, скопируйте содержимое из .env_example в .env, 
для запуска docker-compose заполните нужные поля для приложения:
```
в файле .env
```
3. Запустите Docker Compose:
```
docker-compose up --build
```
4. После успешного запуска ваше Django-приложение будет доступно по адресу:
```
http://localhost:8000
```
5. Для просмотра логов каждого контейнера для отладки их воспользуйтесь командой:
```
docker-compose logs
```
6. Для просмотра запущенных контейнеров:
```
docker-compose ps
```
7. Для проверки работоспособности БД/Redis, подключитесь к контейнеру через:
```
docker exec -it <имя_контейнера> bash
```
(для Redis) Внутри него выполните команду, чтобы получить ответ PONG, что подтвердит работоспособность: 
```
redis-cli  и PING
```
(для БД) Внутри него выполните команду, что подтвердит работоспособность: 
```
SELECT 1;
```
8. Для проверки работоспособности Celery и Beat, смотрите логи, ища сообщения [OK], [INFO] о старте, 
успешном получении задач и их выполнении, отсутствие ERROR, WARNING или FATAL:
```
[OK], [INFO]
```
9. Подключитесь к удаленному серверу (ВМ) через SSH:
```
ssh ваш_пользователь@IP_адрес_машины
```
10. Установите Python, Django и другие зависимости:
```
sudo apt install python3 python3-pip python3-venv nginx gunicorn
```
11. Откройте терминал и выполните команду для обновления списка пакетов: 
```
sudo apt update
```
12. Затем выполните команду для обновления всех установленных пакетов до их последних версий:
```
sudo apt upgrade
```
13. Сначала проверьте состояние файрвола с помощью команды: 
```
sudo ufw status
```
14. Если файрвол отключен, активируйте его: 
```
sudo ufw enable
```
15. Теперь откройте необходимые порты:
```
sudo ufw allow 80/tcp; sudo ufw allow 443/tcp; sudo ufw allow 22/tcp
```
16. После открытия портов проверьте настройки файрвола, чтобы убедиться, что правила применились: 
```
sudo ufw status
```
17. Настройка автозапуска приложения, перейдите в директорию /etc/systemd/system/ с помощью команды:
```
cd /etc/systemd/system/
```
18. Создай или отредактируй файл myapp.service с помощью текстового редактора, например nano:
```
sudo nano myapp.service
```
19. Вставьте следующее содержимое в файл:
```
[Unit]
Description=My Application
After=network.target

[Service]
User=ваше_имя_пользователя
WorkingDirectory=/путь/к/вашему/приложению
ExecStart=/usr/bin/python3 /путь/к/вашему/приложению/myapp.py
Restart=always

[Install]
WantedBy=multi-user.target
```
20. Сохрани изменения: нажми Ctrl + O, затем Enter, чтобы сохранить файл, и Ctrl + X, чтобы выйти из редактора.
21. Обновите конфигурацию Systemd:
```
sudo systemctl daemon-reload
```
22. Запустите сервис:
```
sudo systemctl start myapp.service
```
23. Чтобы сервис автоматически запускался при загрузке сервера, выполните:
```
sudo systemctl enable myapp.service
```
24. Чтобы убедиться, что сервис запущен и работает корректно, используйте команду:
```
sudo systemctl status myapp.service
```
25. Настройте переменные окружения. Для хранения конфиденциальных данных используйте GitHub Secrets.
Чтобы использовать секреты в вашем workflow, их сначала нужно добавить в настройки репозитория.
```
1. Зайдите в репозиторий на GitHub и перейдите во вкладку Settings (настройки).
2. В меню слева выберите раздел Secrets and variables, затем кликните на Actions.
3. Нажмите кнопку New repository secret для добавления нового секрета.
4. Введите имя секрета и его значение. Имя должно быть уникальным и легко распознаваемым.
5. Нажмите Add secret, чтобы сохранить секрет.
```
В настройках репозитория добавьте следующие секреты:
```
1. SERVER_IP — IP-адрес вашего сервера.
2. SSH_USER — имя пользователя для SSH-подключения.
3. SSH_KEY — приватный SSH-ключ для аутентификации.
4. DOCKER_HUB_ACCESS_TOKEN - токен на DOCKER_HUB.
5. DOCKER_HUB_USERNAME - имя пользователя DOCKER_HUB.
```
26. Настройка процесса ручного деплоя вашего веб-приложения.
27. Откройте терминал на сервере и выполните команду:
```
sudo apt update
sudo apt install git
```
28. Убедитесь, что Git установлен корректно, выполнив команду:
```
git --version
```
29. Перейдите в директорию, где вы хотите разместить код вашего приложения.
```
cd /var/www
```
Где /var/www — это директория, куда вы хотите склонировать проект.
30. Затем выполните команду для клонирования репозитория:
```
git clone https://github.com/username/repository.git
```
Замените username/repository на путь к вашему репозиторию. 
31. Перейдите в директорию, где находится ваш файл docker-compose.yml:
```
cd /var/www/repository
```
32. Откройте терминал на сервере и выполните команду:
```
cd /var/www/repository
```
Замените /var/www/repository на директорию, куда проект был склонирован.
33. Выполните команду для запуска контейнеров:
```
docker-compose up -d
```
Чтобы убедиться, что приложение работает, откройте браузер и перейдите по адресу http://localhost

## Использование:

1. В платформе для онлайн-обучения вы можете посмотреть урок по каждому курсу.
2. В каждом уроке вы можете найти необходимые материалы и видео для изучения.
3. В платформе есть оплата за обучения по курсу или по уроку, можно посмотреть дату платежа и кто оплатил и что.
4. Так же можно посмотреть количество уроков на каждом курсе.
5. В приложении добавлены права доступа, владельцы могут просматривать удалять редактировать уроки и курсы.
6. Модераторы могут только просматривать и изменять уроки и курсы.
7. Также есть подписка на обновления курса для пользователя, которая удаляет или создает подписку на курс пользователя.
